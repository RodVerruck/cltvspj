# CLTV SPJ Calculator

Calculadora de Customer Lifetime Value (CLTV) para análise de valor do cliente ao longo do tempo.

## 🚀 Tecnologias

- **Next.js 14** - Framework React
- **React 18** - Biblioteca UI
- **Tailwind CSS** - Estilização
- **Lucide React** - Ícones

## 📦 Instalação

```bash
# Instalar dependências
npm install

# Executar em desenvolvimento
npm run dev

# Build para produção
npm run build

# Iniciar servidor de produção
npm start
```
