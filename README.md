# Calculadora CLT vs PJ

Calculadora completa e blog para comparar regimes de trabalho CLT e PJ no Brasil, com cálculos precisos de impostos e benefícios.

## 🚀 Features

- ✅ **Calculadora CLT vs PJ** - Cálculo preciso com todos os impostos
- ✅ **Blog com 5 artigos** - Conteúdo otimizado para SEO
- ✅ **Design responsivo** - Funciona em todos os dispositivos
- ✅ **SEO otimizado** - Meta tags e estrutura otimizada
- ✅ **Monetização** - Google AdSense e afiliados configurados

## 📊 Artigos do Blog

1. **CLT ou PJ: Qual Vale Mais?** - Guia completo 2026
2. **Como Calcular Salário PJ** - Método passo a passo
3. **PJ para Desenvolvedores** - Análise específica para devs
4. **Como Abrir CNPJ** - Passo a passo prático
5. **Simples Nacional** - Qual anexo escolher

## 🚀 Tecnologias

- **Next.js 14** - Framework React com App Router
- **React 18** - Biblioteca UI
- **Tailwind CSS** - Estilização
- **Lucide React** - Ícones
- **MDX Remote** - Renderização de posts
- **Gray Matter** - Parser de frontmatter

## 📦 Instalação

```bash
# Instalar dependências
npm install

# Executar em desenvolvimento
npm run dev

# Build para produção
npm run build

# Iniciar servidor de produção
npm start
```

## 📁 Estrutura do Projeto

```

├── components/
│   └── AdSense.js            # Componente AdSense

    └── blog.css              # Estilos do blog
```
